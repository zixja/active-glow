# ✨ Active Glow Only

**Active Glow Only** is a lightweight CSS customization designed for **Endcord** that makes the currently selected channel or tab stand out with a clean cyan/blue glow.

Instead of replacing the entire Discord/Endcord appearance with a full theme, Active Glow Only focuses specifically on highlighting the element you're currently using.

## ✨ Features

- 🔵 Cyan/blue active channel glow
- 💡 Glowing selected tab effect
- 🖼️ Glow applied to selected icons
- 🎨 Keeps the original Endcord/Discord appearance
- 📐 No layout or sizing changes
- 🎞️ No animations
- 🪶 Lightweight CSS-only modification
- ⚡ Easy to install and remove

## 📸 What It Changes

When a channel or tab is selected, Active Glow Only adds:

- A subtle cyan/blue gradient
- Glowing border illumination
- Soft outer glow
- Glowing text
- Icon edge glow

Everything outside of the currently selected item remains unchanged.

## 📦 Installation

1. Download `active-glow.css`.
2. Open your Endcord custom CSS/theme location.
3. Add or import `active-glow.css`.
4. Reload or restart Endcord if required.
5. Select a channel or tab to see the glow effect.

## 🎨 Design Philosophy

Active Glow Only was made for users who want their currently selected channel or tab to be obvious without installing an entire custom theme or lighting up the whole interface.

The goal is simple:

> **Highlight what you're using and leave everything else alone.**
